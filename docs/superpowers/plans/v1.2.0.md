# Nebula Cruise v1.2.0 — Fuel Burst & Tutorial

## 设计目标

1. **燃料爆发（Fuel Burst）** — 当燃料 ≥75% 且在地面上时，按 **W / ↑** 可触发一次主动超级加速，消耗 50% 燃料，持续 3 秒。
2. **新手引导（Tutorial）** — 首次进入游戏时，在热身区（前 24 段）显示操作提示。
3. **UI 界面优化** — 增强视觉反馈、按钮光晕、状态指示器。

---

## 燃料爆发（Fuel Burst）

### 规则
- **触发键**：`W` / `↑`（前进键）**按住蓄力 `FUEL_BURST_CHARGE_TIME` (1 秒)** 后自动触发；1 秒内松手则取消并退化为普通跳跃。条件不满足时 `W`/`↑` 立即跳跃。`Space` / `K` 在任何状态下都是跳跃
- **触发条件**：燃料 ≥ `FUEL_BURST_MIN` (75%) + 在地面上 (`playerY <= 0 && playerVY <= 0 && jumpsUsed === 0`) + 不在 BOOST / 无敌状态
- **蓄力反馈**：船体金色能量环随进度收拢增强 + 8 颗环绕火花汇聚（reduced-motion 下静止减半）；燃料条下方金色进度条；1/3、2/3 进度两声渐高提示音；蓄力中条件破坏（起跳/燃料跌破/吃到 BOOST）静默取消
- **消耗**：`FUEL_BURST_COST` (50%)
- **效果**：
  - 速度锁定为 `FUEL_BURST_SPEED` (36 m/s，复用 BOOST_SPEED)
  - 持续 `FUEL_BURST_DURATION` (3 秒)
  - 期间无敌（穿透所有障碍）
  - 最后 `FUEL_BURST_WARN_TIME` (1 秒) 显示预警（3 声渐高 beep）
- **到期**：恢复触发前速度
- **与 BOOST 关系**：互斥，燃料爆发期间不会吃到 BOOST 道具

### 状态变量
- `fuelBurstT: 0` — 剩余时间（秒）
- `fuelBurstPrevSpeed: 0` — 爆发前速度（用于恢复）
- `fuelBurstWarnStage: 0` — 预警阶段（0..3，防重发）
- `fuelBurstChargeT: 0` — 蓄力进度（秒，>0 表示蓄力中）
- `fuelBurstChargeStage: 0` — 蓄力提示音阶段（防重发）

### 实现
- `canFuelBurst()` — 统一的触发条件判定（键盘路由、蓄力维持与 HUD 就绪指示共用）
- `tryFuelBurst()` — 扣燃料、锁速度、音效 `sfxFuelBurst()`、引导标记
- 键盘路由：`keydown` 中 `W`/`↑` → 满足条件开始蓄力，否则 `tryJump()`；`keyup` 未满 1 秒 → 取消蓄力 + `tryJump()`；`updatePhysics` 累积蓄力，满 1 秒自动 `tryFuelBurst()`

### UI
- 燃料条 ≥75% 且在地面时，燃料条边框金色脉冲（Canvas HUD）
- 左侧状态栏显示 "FUEL BURST 3s" → "FUEL BURST ENDING 1s"（位于 BOOST 之后、超级形态之前）
- 船体光环与尾迹：复用 BOOST 的青白光环与速度线粒子

### 音频
- 新增 `sfxFuelBurst()` — 比 BOOST 更厚重的电流 zapp + 上扬轰鸣
- 新增 `sfxFuelBurstWarn(stage)` — 到期预警 3 声渐高 beep（sawtooth，区别于 BOOST 的 square）
- `propulsionAudioMode()` 增加 `fuelBurst` 分支（复用 BOOST 推进音频参数）

## 新手引导（Tutorial）

### 触发
- `localStorage` 标记 `skyroads_tutorial_seen`
- 首次任务自动激活；指挥中心另有 **"新手教学 / Training"** 按钮，无论是否看过都强制进入教学模式
- 引导在热身区（前 24 段）显示

### 引导阶段
1. **变道** — "左右滑动或按 A/D 变道"
2. **跳跃** — "按 Space/K 跳跃"（Space/K 恒为跳跃，不受燃料爆发影响）
3. **滑翔** — "下落时按住跳跃键可滑翔"
4. **射击** — "按 J 发射导弹"
5. **燃料爆发** — "燃料≥75%：按住 W/↑ 1 秒触发燃料爆发！"

### 实现
- `src/tutorial.js` 模块（createTutorialState / startTutorial / updateTutorial / renderTutorial）
- `startTutorial(tutorial, storage, { force })` — 教学模式 force 启动，不清除"已看过"标记
- 在 `render()` 循环中叠加绘制半透明提示框，**顶部显示进度标签（教学 n/5）**，带阶段圆点指示器与渐隐动画
- 每个提示最少显示 2.5 秒，玩家执行对应操作后渐隐并进入下一阶段
- 全部完成或飞出热身区后自动结束，设置 `localStorage` 标记；已看过的玩家不再自动显示
- 阶段计入覆盖所有输入路径：键盘变道（`pressDirection`）与触屏变道（`trySwitchLane`）都标记 `laneChanged`；子弹（`fireBullet`）与蓄力导弹（`fireMissile`）都标记 `shot`

## UI 优化

### CSS 视觉重设计
- 面板：毛玻璃模糊（backdrop-filter）+ 分层辉光阴影 + 更柔和的描边
- 标题：青色→紫色渐变文字 + 双重辉光
- 按钮体系：主行动按钮三段蓝紫渐变（AA 对比度 ≥4.5）+ 悬停浮起；次要按钮幽灵风格；工具按钮胶囊化
- 版本徽章：胶囊形 + 呼吸发光；操作列表：左侧描边条目 + 悬停高亮；键帽（kbd）立体化
- 指挥中心新增"新手教学 / Training"入口按钮

### Canvas HUD
- 燃料条就绪状态：金色脉冲边框（≥75% 且在地面时显示）
- 燃料爆发蓄力进度：燃料条下方金色进度条
- 左侧状态栏增加燃料爆发状态行
