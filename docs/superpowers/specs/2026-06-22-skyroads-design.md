# 太空跳跳车 (SkyRoads) — 设计文档

**日期**: 2026-06-22
**状态**: 已批准

## 概述

一款致敬经典 SkyRoads 的太空跑酷网页游戏。玩家驾驶一辆飞行器在太空中的浮动跑道上疾驰，需要左右变道躲避障碍、跳跃跨过缺口、拾取燃料胶囊维持飞行。单文件 HTML，浏览器打开即玩。

## 技术架构

- **技术栈**: 原生 HTML5 Canvas + JavaScript，零依赖、零构建。
- **交付物**: 单个 `index.html` 文件，内嵌 CSS + JS。
- **运行方式**: 浏览器直接打开 `index.html`。

## 核心玩法

### 视角
第一人称伪 3D。玩家视角位于飞行器后方略上方，跑道沿 Z 轴向远方延伸，通过透视投影在屏幕上呈现收缩效果。

### 操作
- `←/→` 或 `A/D`: 左右变道。跑道为 3 条车道，离散切换，带平滑过渡动画。
- `空格`: 跳跃，用于跨过跑道缺口。
- 飞行器自动持续前进并加速，玩家无需控制油门。

### 三种死亡条件
1. **掉落**: 踩到缺口且未跳跃 → 坠入虚空 → Game Over。
2. **撞墙**: 变道进入被障碍块占据的车道 → 撞毁 → Game Over。
3. **燃料耗尽**: 燃料条归零 → 引擎熄火 → Game Over。

### 燃料系统
- 燃料随时间持续消耗。
- 赛道上随机生成燃料胶囊，飞行器碾过即拾取，补充燃料。
- 燃料条显示在 HUD，归零即触发死亡。

### 计分系统
- 记录最远前进距离（米）+ 本局用时（秒）。
- 使用 `localStorage` 存储最佳记录（最远距离）。
- Game Over 屏显示本局成绩与历史最佳对比。

## 赛道生成

- 跑道由 segment（段）序列拼接，每段固定长度，程序化无限生成。
- 每个 segment 的 3 条车道各自标记为以下之一:
  - `ROAD`: 普通路面，可通行。
  - `GAP`: 缺口，需跳跃通过；未跳则坠落。
  - `WALL`: 障碍块，进入该车道即撞毁。
  - `FUEL`: 可通行路面 + 上方悬浮燃料胶囊，碾过即拾取（拾取后该段降级为普通 ROAD）。
- **可解性约束**（保证赛道永远有解，不出现"必死"组合）:
  - 缺口段（含 GAP 的 segment）至少保留一条 ROAD/FUEL 车道，让玩家可通过变道避开缺口。（跳跃仅作为跨越"全部三条车道都是 GAP"的短段的备选手段，此类全缺口段最多连续 1 段。）
  - 障碍段（含 WALL 的 segment）至少保留一条非墙车道供变道通过。
  - 障碍段与缺口段之间至少间隔 N 段 ROAD，确保玩家有反应时间。
  - 燃料胶囊的生成密度需保证：在正常操作下，燃料补充速率 ≥ 消耗速率（避免死局）。

## 伪 3D 渲染

### 透视投影
跑道是沿 Z 轴延伸的 segment 序列。每一帧取玩家位置之前的若干 segment，从远到近绘制。

对 segment 的每个 3D 点 `(x, y, z)`（z 为距玩家的距离）投影到屏幕:

```
scale = cameraDepth / z          // z 越大 scale 越小，远处收缩
screenX = width/2 + scale * x * width/2
screenY = height/2 - scale * y * height/2
```

### 渲染顺序
采用画家算法：远处 segment 先画，近处后画，自然形成遮挡关系。

### 背景
画布背景为深空渐变 + 随机星点（星空），远处可叠加星云感渐变，营造太空氛围。

## 游戏状态机

```
MENU (标题屏)
  ↓ 按空格开始
PLAYING (游戏中)
  ↓ 触发任一死亡条件
GAME_OVER (结束屏)
  ↓ 按空格重开 / 按 Esc 回标题
MENU 或 PLAYING
```

## 文件结构（单文件内分区）

```
index.html
├── <style>          # 全屏黑色背景、Canvas 居中、UI 覆盖层样式
├── <canvas>         # 游戏画布
├── <script>
│   ├── 常量配置     # 车道数、速度、燃料消耗率、segment 长度等
│   ├── 输入处理     # 键盘事件监听
│   ├── 赛道生成器   # segment 工厂 + 可解性约束
│   ├── 渲染器       # 透视投影 + 背景星空 + 赛道 + 飞行器
│   ├── 物理与碰撞   # 前进、跳跃弧线、变道插值、碰撞检测
│   ├── 游戏状态机   # MENU / PLAYING / GAME_OVER 切换
│   ├── 主循环       # requestAnimationFrame
│   └── UI           # HUD（燃料条/速度/距离）、Game Over 屏、最佳记录
```

## 不做的事 (YAGNI)

以下功能明确不在 v1 范围内，避免过度设计:

- ❌ 关卡分段 / 终点（v1 为无限跑酷模式）
- ❌ 手动换挡（自动加速）
- ❌ 音效与音乐（v1 静音）
- ❌ 移动端触屏支持（v1 仅键盘）
- ❌ 存档系统 / 多关卡选择菜单

## 成功标准

- 浏览器打开 `index.html` 即可游玩，无需安装任何依赖。
- 三种死亡条件都能正确触发并进入 Game Over。
- 伪 3D 渲染流畅（目标 60 FPS），有明显的太空纵深感。
- 赛道无限生成且永远可解，不会出现必死组合。
- 燃料、距离、最佳记录系统正常工作。
- 键盘操作响应灵敏，跳跃和变道手感自然。
