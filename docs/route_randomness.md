# 每局随机路线

## 问题与检查结果

2026-09-24 用户反馈障碍和奖励像是每局固定重复。基线 `ad2eb09` 的真实开局链路为 `startGame → resetGame → buildTrack → newGenState`，普通生成器使用 `Math.random`，没有复用上一局地图。连续六次真实开局的首 400 段指纹均不同。

重复感来自三维装饰：高架、断桥、挑战墙和支路奖励按里程套用相同模板，普通道具类型也固定按加速、减速、变身、磁铁轮换。六局各 40 公里的审计中，约 34.0% 的最终障碍格、29.6% 的最终奖励来自固定模板；安全通道还会清除约 67.4% 的原随机障碍，使模板更显眼。该统计只描述基线，原始证据保存在本机 `~/.local/state/skyroads_route_randomness_delivery/baseline_run_randomness_audit.json`。

## 当前规则

- 每次开始、重开或重进教学，都生成新的非零路线种子。普通障碍、奖励和敌人生成使用本局独立随机流；特效或音频调用随机数不会影响后续关卡。
- 三维地形通过 `createForRun(seed)` 创建独立实例，物理、渲染、无人机巡逻与虫洞调度共享该实例。局内查询顺序、暂停、折跃或画面恢复不会重抽地图。
- 每局地形起始位置在 48～80 段内变化；每个 240 段周期从山脊、先谷后坡、双峰、长高台四种主路结构中选取一种，每四个周期洗牌一次。除高架左右、高程、谷深和挑战落点外，上下坡顺序与平台长度本身也会变化。
- 每个周期约三分之二概率带独立浮岛；两处支路断桥分别决定是否出现，可以没有、只有一处或同时有两处。断桥仍为两格宽，保留中央绕行；无岛周期不生成浮岛缺口，原岛上能源转移到安全支路。
- 额外支路补给仍为每周期五枚能源、一个变身候选。通用奖励每四次布置机会洗牌一次，各含加速、减速、变身、磁铁；布置机会的概率和最小间隔保持原值。加速／变身候选还会经过全部来源共用的时间间隔过滤，同类生效期间不能拾取续时；详见[后续奖励间距修正](endless_cruise_balance.md#2026-09-25同类奖励按持续时间拉开间距)。
- 高架、浮岛道具只在安全窗口变换，不落在缺口上。普通能源保底、教学、加速曲线、碰撞体与跳跃参数保持原值。
- 虫洞随本局高架生成，首个入口为 11.36～11.68 公里；后续仍按六／七地形周期交替，成功折跃六公里后仍需普通飞行 8.4～10.8 公里。入口相对高台高度、二／三跳难度、容错、增益冻结和两秒出口保护保持原值。
