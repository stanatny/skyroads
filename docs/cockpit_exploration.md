# 3D 追尾与分层航道探索

2026-09-21，分支 `explore/cockpit_3d`，基于 `origin/main` 的 `cd520f1`。
本记录汇总本轮 3D 探索的设计与本地、内网验收结果；线上部署和原生安装包验证单独进行。

## 当前体验

玩家驾驶 NC-12 Manta R 掠过多层太空航道。相机的横向位置和高度跟随飞机真实位置，飞机保持画面中央偏下；道路、障碍与环境产生相对运动。七车道操作、跃升、滑翔、武器、燃料爆发和道具继续使用现有输入。

飞行器使用珊瑚红主装甲、深蓝骨架、象牙识别条与电青尾焰；新增短鸭翼、后掠刃形翼尖和斜尾翼，保留连续翼身与内嵌双涡轮。超级模式展开厚肩翼与尾部动力环，形成明显不同的轮廓；减少动态效果时直接切换形态。机体在内部节点统一缩至上一版线性尺寸的 43%，普通翼展约 1.67、超级约 2.43 个渲染单位，均小于 3.4 的单格宽度。实体和尾焰共同缩放，根节点仍保持物理位置。模型更新不修改玩法状态，重新开始会清除上一局的展开状态。

巡航保持清楚的蓝白尾焰，滑翔时双发切为持续的暖色长焰并向下偏转；超级形态的环形推进器同步增强。尾焰直接跟随真实滑翔状态，落地、松开或燃料不足时恢复巡航表现，超级加速保留更强的蓝色喷焰。减少动态效果时保留静态持续喷焰。

蓄力特效跟随机身位置与姿态：W / ↑ 燃料爆发蓄力显示青蓝光粒向推进器汇聚，能量弧收拢、尾焰增亮；J 导弹蓄力显示金色光粒与反应核心。蓄满提示一次，燃料爆发激活时释放短促光环，取消即收起。暂停冻结，重开清空；减少动态效果时保留静态亮度反馈，关闭粒子与旋转。特效使用固定资源，不改变蓄力或发射规则。

撞击或坠毁时，机身位置触发一次独立的爆炸，机体隐藏后火光、冲击环、装甲碎片与余烬继续衰减。主动燃料爆发、拾取超级加速道具及爆发结束后的 1 秒缓冲保护，均以透明护盾包住飞机，HUD 同时显示“无敌保护”及连续剩余时间。机体和 HUD 共用状态读取函数，从加速生效起显示，爆发接续缓冲保护时不闪断；所有加速和保护计时均到期才消失，不延长无敌。暂停保留护盾，重开或回菜单清除上局特效；减少动态效果保留低强度反馈。

HUD 改为两侧遥测及底部轻量统计，中央留给飞机与前路。“贴地巡航”、上坡、下坡和高架状态固定在左上角。地形小图用金色顶边标识高架路块；中文、英文、窄屏、暂停和兼容画面分别处理。

三档障碍具有不同实体轮廓：斜面装甲路障、凹陷反应核心、分层防御塔。低/中障碍保留一/二青带，高塔使用顶部金色信标。近远模型共享同一物理包络，几何按材质合批；无人机和炮台也重建为楔体、后掠翼、倒角装甲及套筒炮口。

远景为程序化星云、行星与分层轨道枢纽；近景包含随行程和道路高程移动的悬臂服务设施。程序化环境反射仅初始化烘焙一次，主机、近障碍和敌机产生局部柔和投影，背景不参与投影。

## 地形与玩法

- 主航道使用连续平滑的上坡、高原与下坡，首轮高程达到 6 个渲染单位，后续逐步升至 8。
- 主高架比主航道再高 2 至 2.6 个渲染单位，左右随轮次交替；对侧还有错开入口与出口的较低支路。
- 高架包含两处交错的双段断桥，另一条桥道始终连续。桥上提供额外燃料与超级模式道具，中层侧道保留逐级障碍和固定炮台；中央道可持续绕行。
- 后半段加入三种深度的连续谷地，周期末以零坡率接回平路。坡入口、断层落地和周期出口预留横移余量，动态敌机不闯入保护区域。
- 无人机保留在合法挑战车道，巡逻只进入同高程且无障碍、缺口或道具的相邻车道；两侧受限时悬停。修复此前分层地形区把所有无人机过滤掉的问题，保留原始生成概率和完整安全区，关闭地形后的旧版换道行为保持不变。
- 断层和横向驶离高台会真实下落，忽略已经离开的原台后缘；落地后恢复正常驾驶。低层横切高台时停在台边，不判坠毁，纵向仍继续前进。台边间距同步收至 0.44 格；3D 墙体与敌机核心的侧向碰撞半宽统一为 0.42 格，覆盖超级形态含侧倾的最大翼展。兼容视图保留原来的碰撞宽度，缺口与拾取保留中心支撑规则。保持方向并跳到足够高度可上台，也能立即反向离开。
- 长按横移取消道与道之间的等待和反复减速；点按保留单道移动，松开平顺收束。同向键别名交接不会误停，相机和倾斜姿态使用真实位置/速度。
- J 蓄力 1.5 秒松开后发射有实体、尾焰、连续烟迹与冲击爆炸的导弹。导弹以受限爬升速度避开前方缓坡，不能穿过台边；普通子弹保留固定世界高度。特效采用固定资源池，暂停冻结，重开清空。

`playerY` 保留“离地高度”语义，`groundHeight` 表示支撑路面的绝对高程。模型、相机、碰撞及弹道统一从这两个量换算，避免只改变视觉。WebGL 初始化失败或运行中丢失时，画面和物理一起切回平路；保持当前进度、相对跳高、计分和存档。暂停中回退会补绘静态画面，不恢复物理计时。

首轮可复核位置：64–104 段为主上坡，90–120 段为右侧低支路入口，120–144 段为左侧高架入口，156–157 / 174–175 段为交错断桥，192 段为高架断层，232–288 段为谷地。后续轮次左右交替并改变谷深。位置编号用于开发复核，不作为玩家界面内容。

## 内网试玩

用户已授权内网预览。受限静态服务只暴露入口、脚本、样式和素材，直接读取工作区，刷新即可更新。原回环服务保留；内网进程脱离聊天终端运行，配有随服务退出的临时防空闲休眠。

具体 IP、监听端口、进程身份、日志、检查记录和停止方式位于本机 `~/.local/state/skyroads_cockpit_preview/lan_state.json`。已从主机通过内网 URL 检查资源、刷新更新和完整浏览器操作；未独立确认另一台设备的连通性。试玩要求 Mac 保持开机联网，访问设备与它处于可互通的局域网或私有网络。

当前验收以桌面浏览器为主；实体手机与 macOS 原生 WebView 安装包未做本轮实机验证。

## 2026-09-21：轨道工业美术重做，等待 review

基线为已合入 main 的 `bdc003a`；继续使用 `feat/3d_visual_polish`。用户验收 Kimi 的初步美化后认为效果不足，要求 Codex 接手。该轮以建筑、无人机、水晶、奖励和 HUD 的造型重做替代此前只增加信号灯、光环和拾取光柱的做法；不改变追尾、操作、地形、碰撞、变形或无敌规则。当前仅为工作区内网预览，不自动更新线上版本或提交。

建筑使用象牙陶瓷、钴蓝装甲和石墨凹舱的大色块：低障碍为带液压杆的切角装甲闸机，中障碍为偏置涡轮电站与独立冷却筒，高障碍为退台塔身、不等高扶壁和凹入楼层。保留一条／两条高度识别横灯与高塔红色警示。近远模型仍严格落在相同物理包络，按两类材质实例化。

新模块 `src/flight_objects.js` 在初始化时生成并合并全部模型：无人机有分段后掠翼、双涵道、红色传感眼和换道方向提示；炮台有固定底座与整体转向的双联炮塔。燃料为带金属托架的多晶面晶簇；BOOST、SLOW、TRIPLE、MAGNET 分别使用双箭头推进模块、时间陀螺、三芯装置与马蹄形磁体。每类奖励保留自己的色彩与轮廓，地面使用小型定位灯，不再竖立贯穿视线的光柱。模型只读取状态，不创建独立动画循环。所有新增材质与几何登记到 renderer 的资源所有者，实例批次固定，销毁随现有生命周期执行。

场景采用一致的冷色主光、环境反射和局部阴影；背景设施配色同步到陶瓷／钴蓝，路板新增确定性的加工细纹与低对比实漆方向标，亮度低于危险与奖励信号。全部美术由仓库内可编辑的参数化脚本生成，没有新增下载素材、第三方许可或运行时网络依赖。

HUD 改为两侧切角仪表，突出速度、燃料与武器状态；菜单使用任务卡和七航道简报。窄屏将教学、低燃料与保护状态放入同一纵向信息流，避免同时出现时相互覆盖。中英文、焦点、暂停、减少动态与经典画面回退继续使用原有状态和交互来源。
