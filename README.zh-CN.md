# 星云巡航 / Nebula Cruise

《星云巡航》是一款画面精致、节奏明快的浏览器科幻跑酷游戏。驾驶细节丰富的飞船穿过程序生成的无尽星云，观察前方道路，连续跳跃、蓄力开火、收集强化道具，并向本机 Top 15 发起挑战。

在线游玩：https://stanatny.github.io/skyroads/

## 游戏亮点

- 灵敏的连续移动：按住左或右可以丝滑地跨越多条车道，反向操作时会立即掉头。
- 中英双语的星际指挥中心、精细飞船、自托管 UI 素材，以及原创的三轨自适应配乐 **Nebula Cruise**。
- 无限延伸、逐渐加速且保证存在可达路线的赛道，包含燃料压力、缺口、窄桥、障碍、敌机，以及加速、超级形态、磁铁和减速道具。
- 可靠的本机 Top 15。首次游玩会从原创、安全的科幻呼号列表中随机选择玩家名，之后自动沿用；需要时可以随时改名。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | 按住 `A` / `D` 或 `←` / `→` | 向左或向右滑动 |
| 跳跃 | `K`、`Space`、`W` 或 `↑` | 点按 |
| 二段跳 | 空中再次按跳跃键，消耗 3 点燃料 | 空中再次点按 |
| 滑翔 | 下落时按住跳跃键，会持续消耗燃料 | 仅键盘 |
| 开火 | 点按 `J` | 仅键盘 |
| 蓄力导弹 | 按住 `J` 3 秒后松开 | 仅键盘 |
| 开始 / 再来一局 | `Space` 或 `Enter` | 使用画面按钮 |
| 暂停 / 继续 | `P` | — |
| 任务结束后返回指挥中心 | — | 使用“返回指挥中心”按钮 |
| 总声音开关 | `M` | 使用独立的音乐、音效按钮 |

矮墙可以跳过；高塔需要变道、超级形态跳跃或武器处理。子弹和蓄力导弹采用不同的碰撞规则；下落时按住跳跃键会进入消耗燃料的滑翔。HUD 会显示燃料、跳跃次数、得分、距离、用时、速度、蓄力、强化倒计时和声音状态。

## 障碍路线提示

防御模组使用统一的视觉提示：

- **1 条青色灯带 — 600 世界单位：** 一段跳即可越过。
- **2 条青色灯带 — 1,250 世界单位：** 需要二段跳。
- **金色信标 — 2,000 世界单位：** 需要超级形态的三段跳。
- **发光矮墙连排：** 推荐路线是一段跳后在下落时按住跳跃键滑翔；时机准确的二段跳也是可接受的替代方案。
- **发光中墙连排：** 必须二段跳后在下落时按住跳跃键滑翔。
- 每个新增的进阶建筑或连排挑战都保留一条普通绕行车道。原有的七车道全缺口挑战按设计保持不变。

## 语言与本机记录

游戏支持中文和英文。如果浏览器的任一系统语言是中文（包括简体和繁体地区），首次启动会显示中文；其他系统语言统一显示英文。可通过 `中文 / EN` 按钮手动切换，选择会保存在当前浏览器中。

每局结束后会按得分、距离和用时参与排名。本机 Top 15 仅保存在当前浏览器中，并使用可恢复的主备本地存储。游戏会自动沿用当前玩家名，改名是可选操作。清除浏览器站点数据也会清除排行榜和偏好设置。

## 本地运行

不需要安装依赖或执行网页构建。现代浏览器可直接打开 `index.html`：

```bash
open index.html
```

为了获得兼容性最好的本地体验，也可以在仓库目录启动本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

开发者可以运行完整自动化检查：

```bash
npm test
npm run check
```

## macOS 应用

在已安装 Xcode 命令行工具的 macOS 12 或更高版本上，运行以下命令构建同时支持 Apple Silicon 和 Intel 的通用应用：

```bash
bash app/build.sh
```

准确的输出文件名是仓库根目录下的 `Nebula Cruise.app`。应用会在本地 WebKit 中运行完整游戏和全部内置素材。公开构建可从 [GitHub Releases](https://github.com/stanatny/skyroads/releases) 下载。
